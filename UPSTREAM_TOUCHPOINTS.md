# Upstream touchpoints

Every edit this project makes to a file that exists upstream, so pulling new Metrolist
releases stays manageable. The interface-style switch (preference key, setting, settings
ordering) was removed after M3 with the stock desktop UI, and those four upstream files are back to
upstream's version. Project-only files (PLAN.md, `docs/xmb-*.md`, `reference/`,
`compare/`, `scripts/xmb/`, the `xmb_` Compose resources, the `xmb` and `visualizer` packages and
the `desktop/xmb` host) aren't listed.
